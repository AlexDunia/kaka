# Project voice

For every user-facing string in this repository, follow the voice and tone in
docs/VOICE_AND_TONE.md.

This applies to new features, generated sample data, headings, helper text, buttons,
empty states, validation, errors, success messages, loading states, emails, dashboards,
and authentication screens.

Do not change layout or styling merely to apply the voice. When a task is about copy,
keep the existing structure, classes, behavior, and data intact.
