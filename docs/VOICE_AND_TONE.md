# Rush Hour voice and tone

Rush Hour is ticketing software that helps organisers create events, welcome attendees,
sell tickets, and understand how their event is growing.

## Core voice

Write like a calm, capable event partner:

- Warm and encouraging, without sounding childish or overly excited.
- Clear and concise, with the next action easy to understand.
- Event-first: talk about the organiser's event, attendees, tickets, and progress.
- Helpful and practical, especially when something needs attention.
- Confident but never pushy, blaming, or alarmist.
- Human and conversational, using natural language such as “Let’s”, “you”, and “your”.

The product voice should feel consistent with the Create Event flow and the updated
Dashboard: friendly guidance with the direct, action-led clarity associated with leading
ticketing products such as Eventbrite.

## Writing rules

- Use sentence case for headings, labels, and buttons.
- Prefer short sentences and familiar words.
- Lead with what the user can do or what has happened.
- Explain why an action helps when useful.
- Use contractions naturally: “you’re”, “we’ll”, “can’t”.
- Keep button labels specific: “Create event”, “Send reset link”, “View public page”.
- Make errors recoverable: say what happened and what the user can try next.
- Make success messages reassuring and point to the next step.
- Refer to customers as “attendees” or “buyers” according to context.

## Avoid

- Corporate analytics language: “conversion optimisation”, “performance drag”, “traffic acquisition”.
- Commands that sound scolding: “Do not overthink”, “Fix this now”, “Be careful”.
- Pressure without help: “Urgent”, “Failing”, “Poor performance”.
- Empty hype: “Revolutionary”, “Best ever”, “Game-changing”.
- Generic system language: “Operation successful”, “Processing request”.
- Unnecessary exclamation marks or title case.

## Examples

| Instead of | Write |
| --- | --- |
| Login to your account | Welcome back |
| Registration successful | You’re all set |
| General Admission is the drag | General Admission has room to grow |
| Do these in this order | A few things you can do next |
| Operation failed | We couldn’t complete that. Please try again. |
| Loading | Getting things ready… |

## Tone by moment

- Creation: optimistic and guiding — “Let’s build your event.”
- Dashboard: supportive and useful — “See how your event is growing.”
- Sales: encouraging, never pressuring — “A simple offer could help more people book.”
- Event day: calm and welcoming — “You’re ready to welcome attendees.”
- Authentication: reassuring and direct — “Welcome back. Your events are waiting.”
- Errors: calm and actionable — “We couldn’t log you in. Check your details and try again.”
- Success: warm and forward-looking — “You’re all set. Let’s get started.”
